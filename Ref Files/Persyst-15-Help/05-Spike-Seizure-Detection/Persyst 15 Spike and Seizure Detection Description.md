# Persyst 15 Spike and Seizure Detection Description

# **Persyst 15** **Spike and Seizure Detection Description**

The Persyst
spike and seizure detector
is for
scalp EEG recordings that use
the 10-20 labeling convention.
This software is intended for use by neurologists or EEG technicians.
