# Quick Tour: Performing a Scan

### **Quick Tour: Performing a Scan**

From the System Button Bar, click the **Tools** button and then the **Spike Detection** button. Select the desired **Protocol**, then **Process**.

When the scan is complete, the status window will display the message **WaitingForData**.

![image\79Reveal.gif](../assets/79Reveal.gif)

**AutoStart:** Reveal will begin scanning the EEG with the protocol selected as soon as it is launched.

**AutoEnd:** Reveal will close automatically when the end of the file is reached (off-line), or after 10 minutes if no new data is recorded (on-line).

**Continue Previous:** Reveal will start where it left off during the last scan, e.g., if 10 hours of the recording was scanned and Reveal is closed and restarted (e.g., if a new scanning protocol is selected), Reveal will start scanning at hour 10.

**Save Auto & Continuous Settings:** Select to save the current selections for AutoStart, AutoEnd, and Continue Previous for the next recording processed with Reveal.

**ShadowFolder:** Used to store the spike and seizure detection results file (\*.sd4) to another location. This might be used when scanning a file from a CD-ROM disk (or other read-only disk) and storing the results file to your hard drive. Use the **Subfolder Per Record** option to create a separate subfolder for each recording’s results file (this can help organize result files on systems that store all the EEG recordings in a single folder).
