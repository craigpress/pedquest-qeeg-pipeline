# Persyst Command Line Interface

# Persyst Command Line Interface (PSCLI.exe)

The
Persyst Command Line Interface program (PSCLI.exe) can be used to automate
the processing of EEG recordings off-line, export results in CSV format,
and archive EEG using the command line switches listed below. The list
below is generated by running C:\Program Data (x86)\Persyst\Insight\PSCLI.exe/?.
 

C:\Program
Files (x86)\Persyst\Insight>pscli.exe/?

NAME

  PSCLI
-- Run various Persyst EEG commands.

SYNOPSIS

  PSCLI

    /SourceFile=<SourceFile>

    [/FileType=<FileType>]

    [/Jobs=<Count>]

    [/NoFreeSpaceCheck]

    [/SortByStartTime]

    [/Archive]

    [/OutputFile=<OutputFile>]

    [/Options=<XMLFile>]

    [/Downsample=<Default|Off|On>]

    [/ExportCSV]

    [/Process]

    [/DetectSeizures]

    [/CheckForValid=<Disabled|Files|Processtime>]

    [/PerceptionThreshold=<double>]

    [/DurationThreshold=<double>]

    [/MMX=<MMXFile>]

    [/Panel=<TrendsPanel>]

    [/ArtifactReduction=<Default|Off|On>]

    [/TempDir=<Directory>]

    [/CommandFile=<XmlCommandList>]

    [/Help]

    [/Version]

DESCRIPTION

  The
Persyst Command Line Interface (PSCLI) exposes the following

  EEG
record operations.

  GLOBAL
ARGUMENTS

    /SourceFile=<SourceFile>

      The
source files to operate on. This argument is required for

      all
operations. If the path contains spaces then it will need

      to
be specified in double quotations.

      DEFAULT:
No default provided.

      EXAMPLE:
"/SourceFile=C:\EEGs\EEG\_1\EEG\_1.lay"

        The
operation will be run on the single record

        "C:\EEGs\EEG\_1\EEG\_1.lay".

      EXAMPLE:
"/SourceFile=C:\EEGs\\*.lay" The operation will be

      run
on all ".LAY" files in the directory "C:\EEGs\" and
its

      subdirectories.

    /FileType=<FileType>

      The
type of the source file that was specified.

      DEFAULT:
PersystLayout

      EXAMPLE:
"/FileType=NihonKohden"

    /Jobs=<Count>

      If
the /SourceFile argument contains an asterisk to specify

      multiple
records, then the /Jobs specifies the maximum number

      of
concurrent operations to run at any given time. It is

      ignored
if processing a single record. It is recommended to

      not
exceed the default value to avoid an unresponsive system.

      DEFAULT:
The number of supported hardware threads minus one.

      (This
allows for one thread to handle user interaction and

      other
programs.)

      EXAMPLE:
"/Jobs=7"

        Run
the requested operation on 7 records at a time.

    /NoFreeSpaceCheck

      Allows
the command to run in low free space conditions.

    /SortByStartTime

      Sorts
studies by start time when operating in batch mode.

      Causes
studies to be opened one extra time before running any

      commands.

  ARCHIVE
OPERATION (a.k.a. Clip\Export)

    /Archive

      Specifies
that the source file should be archived to a

      separate
file. The archive settings which were last used in

      the
graphical Persyst application will be used if an XML file

      is
not specified.

    /OutputFile=<OutputFile>

      The
path on disk to store the archived record to. This

      argument
is incompatible with "/Options". This argument cannot

      be
the same as "/SourceFile". If the path contains spaces then

      it
will need to be specified in double quotations.

      DEFAULT:
No default provided in single record mode. In batch

        mode
if the input files are [A\A.lay, B\B.lay, C\C.lay] then

        the
output files will be [A-clip\A-clip.lay,

        B-clip\B-clip.lay,
C-clip\C-clip.lay]. Take care to name the

        input
files uniquely.

      EXAMPLE:
/OutputFile="C:\EEGs\EEG\_1-clip\EEG\_1-clip.lay"

        The
source file will be archived to

        "C:\EEGs\EEG\_1-clip\EEG\_1-clip.lay"

    /Options=<XMLFile>

      A
path to an XML file that contains the settings for the

      archive
operation. This argument is incompatible with

      "/OutputFile".
If the path contains spaces then it will need

      to
be specified in double quotations.

      DEFAULT:
No default provided.

      EXAMPLE:
/Options="C:\EEGs\EEG\_1\EEG\_1.xml"

        The
archive operation will use the settings contained in

        "C:\EEGs\EEG\_1\EEG\_1.xml".

    /Downsample=<Default|Off|On>

      Downsample
records with sampling rate above 300 Hz. Requires

      /Archive.

      DEFAULT:
The value that was last used in the Persyst GUI.

      EXAMPLE:
"/Downsample=Off"

        Disable
downsampling for this operation.

  PROCESS
OPERATION

    /Process

      Process
the trends for the record.

    /MMX=<MMXFile>

      Processes
trends using the specified MMX.

      DEFAULT:
The MMX that was last used in the Persyst GUI.

      EXAMPLE:
"C:\EEGs\Custom.MMX"

  EXPORT
CSV OPERATION

    /ExportCSV

      Exports
the trends from the default MMX and trend panel to the

      specified
CSV file.

    /OutputFile=<OutputFile>

      The
path to the CSV on disk that will store the exported

      samples.
This argument cannot be specified with an asterisk in

      the
"/SourceFile" argument. The default name is

      "<DATE>\_<TIME>\_<PATIENT>.csv".
If the path contains spaces

      then
it will need to be specified in double quotations.

      DEFAULT:
No default provided.

      EXAMPLE:
/OutputFile="C:\EEGs\EEG\_1\EEG\_1.csv"

        The
source file's samples will be exported to

        "C:\EEGs\EEG\_1\EEG\_1.csv".

    /MMX=<MMXFile>

      Exports
the trends based on the specified MMX.

      DEFAULT:
The MMX that was last used in the Persyst GUI.

      EXAMPLE:
"C:\EEGs\Custom.MMX"

    /Panel=<TrendsPanel>

      Specifies
the trends panel to export to the CSV file.

      DEFAULT:
The last panel used in the Persyst GUI.

      EXAMPLE:
/Panel="aEEG"

        The
aEEG trends panel will be exported to the CSV.

    /ArtifactReduction=<Default|Off|On>

      Use
artifact reduced data for the requested operation.

      DEFAULT:
The value that was last used in the Persyst GUI.

      EXAMPLE:
"/ArtifactReduction=Off"

        Disable
the use of artifact reduced data for this operation.

  DETECT
SEIZURES OPERATION

    /DetectSeizures

      Detect
seizures using the Persyst 14 seizure detector.

    /CheckForValid=<Disabled|Files|ProcessTime>

      The
type of verification to run against the record.

      "Disabled":
No verification will be performed.

      "Files":
The record must have files with extensions of

        ".MG2.AF1",
".MG2.AF2", and ".SD4". This is a shallow check

        and
does not verify the contents of these files.

      "ProcessTime":
The record must be processed to the end.

      DEFAULT:
ProcessTime

      EXAMPLE:
/CheckForValid=Disabled

    /PerceptionThreshold=<double>

      The
seizure detection perception threshold.

      DEFAULT:
0.1

      EXAMPLE:
/PerceptionThreshold=0.2

    /DurationThreshold=<double>

      The
seizure detection duration threshold.

      DEFAULT:
1.0

      EXAMPLE:
/DurationThreshold=8

  MERGE
OPERATION

    /Merge

      Merge
a set of records into one.

  MISCELLANEOUS
ARGUMENTS

    //,
 /ignore\_rest

      Ignores
the rest of the labeled arguments following this flag.

      This
is useful for changing out sets of operations on the

      command
line.

    /TempDir=<Directory>

      Sets
the temporary directory used for intermediate files.

      Currently
only affects /Merge.

    /CommandFile=<XmlCommandList>

      Instead
of parsing command line arguments, take arguments from

      the
given XML file. Should support many workflows, but

      currently
only used internally by /Merge.

    /Version

      Displays
version information and exits.

    /h,
 /help

      Displays
this help text and exits.

  ERROR
HANDLING

    In
"single record" mode -- where /SourceFile parameter specifies

    a
single EEG -- if an error occurs, the error will be emitted on

    the
standard error stream and the application with exit with

    errorlevel
set to 1. Efforts have been made to avoid writing out

    bad
data, however the output of a command that exits with

    errorlevel
1 should be discarded.

    In
"batch record" mode -- where /SourceFile specifies more than

    one
EEG -- there can be multiple errors occurring at once. If an

    error
occurs for a single EEG, then the error is emitted on the

    standard
error stream and the processing for \_only\_ that EEG is

    stopped.
The other EEGs will continue to be processed until all

    have
either reported a success or failure.

    After
the final EEG has been processed, the application will

    exit
with errorlevel 1 if there have been any errors at all.

    E.g.:
nine records were processed successfully but one failed so

    the
application will exit with errorlevel 1.

    If
the application exits with errorlevel 1 then it is necessary

    to
read the log to determine which record failed and why. In

    single
record mode this is straightforward. In batch record

    mode,
the error must be correlated with the other messages

    emitted
when processing the specific record. Messages emitted

    for
a specific record can be identified by the "process id",

    which
is prepended in chevrons (e.g. "<12345>") to each message.

    For
both single and batch mode if no errors occurred then the

    application
will exit with errorlevel 0.

  EXAMPLES

    PSCLI
/SourceFile="C:\EEGs\EEG\_1\EEG\_1.lay" /Archive

      /OutputFile="C:\EEGs\EEG\_1-clip\EEG\_1-clip.lay"

      Archives
the record "C:\EEGs\EEG\_1\EEG\_1.lay" to the file

      "C:\EEGs\EEG\_1-clip\EEG\_1-clip.lay"
using the settings that

      were
last used in the graphical Persyst application.

    PSCLI
/SourceFile="C:\EEGs\EEG\_2\EEG\_2.PNT"

      /FileType=NihonKohden
/Archive

      /OutputFile="C:\EEGs\EEG\_2\EEG\_2-clip\EEG\_2-clip.lay"

    PSCLI
/SourceFile="C:\EEGs\\*.lay" /Archive

      Archives
all the .LAY records in the directory "C:\EEGs\"

      and
its subdirectories using the default output file name.

      This
means that "C:\EEGs\EEG\_1\EEG\_1.lay" will be archived

      to
"C:\EEGs\EEG\_1-clip\EEG\_1-clip.lay".

    PSCLI
/SourceFile="C:\EEGs\\*.lay" /Archive /Jobs=3

      The
same as the previous example but limits the number of

      concurrent
jobs to 3. All the same records will be processed,

      but
there will only be 3 being processed at any given time.

    PSCLI
/SourceFile="C:\EEGs\EEG\_1\EEG\_1.lay" /ExportCSV

      /OutputFile="C:\EEGs\EEG\_1\EEG\_1.csv"

      Creates
the CSV file "C:\EEGs\EEG\_1\EEG\_1.csv" that

      contains
the time samples from the montage which was last used

      in
the graphical Persyst application.

    PSCLI
/SourceFile="C:\EEGs\\*.lay" /ExportCSV

      Creates
CSV files (from the last used montage) from all LAY

      files
in "C:\EEGs\" and its subdirectories. The default name

      will
be used for each output CSV file.

    PSCLI
/SourceFile="C:\EEGs\EEG\_1\EEG\_1.lay" /DetectSeizures

      Seizure
detection comments will be added to the record

      "C:\EEGs\EEG\_1\EEG\_1.lay".

    PSCLI
/SourceFile="C:\EEGs\EEG\_1\EEG\_1.lay" /DetectSeizures\

    /CheckForValid=Disabled

      The
same as the previous example, but no validation of the

      record
will be performed.
