# Trend Preferences: Trends

# **Trend Preferences: Trends**

Create, Edit, Duplicate, or Delete trends. Trends are displayed within a Trend Panel.

**Create:** Create a new trend based on a Calculation Engine.

**Replicate****:** Replicate the selected trend. Use this option when creating multiple trends that share most settings between them, e.g., identical trends for different channels or Channel Lists.

**Edit:** Edit the settings for the selected trend

**Delete:** Delete the selected trend.
