# Trend Preferences: Panel

# **Trend Preferences: Panel**

Panels are display configurations comprised of one or more trends. You can create new trend panels, duplicate, rename, or delete them.

**New:**
Create a new Trend Panel

**Duplicate:**
Duplicate the currently selected Trend Panel. Use this to create and save variations of an existing Trend Panel.

**Rename:**
Rename the currently displayed Trend Panel.

**Delete:**
Delete the currently displayed Trend Panel.

**Add:**
Add a trend to the currently displayed Trend Panel.

**Up (panel):**
Move the currently selected panel up within the Panel List.

**Up** **(trend)****:**
Move the currently selected trend up within the currently displayed Trend Panel.

**Edit:**
Edit the currently selected trend within the currently displayed Trend Panel.

**Down** **(trend)****:**
Move the currently selected trend down within the currently displayed Trend Panel.

**Down** **(panel):**
Move the currently selected panel
down
within the Panel List.

**Delete:**
Delete the currently selected trend within the currently displayed Trend Panel.

Important: Changes are not saved until **Save**
or **Save As**
is selected.

**Open:**
Open a Trend Definitions file (note that any unsaved changes to the currently opened Trend Definitions will be lost).

**Save:**
Save changes made to the currently opened Trend Definitions file.

**Save As**
: Save changes to the currently opened Trend Definitions file to a new Trend Definitions file.

**OK:**
Apply the current changes to the Trend Panel. If changes to the Trend Panel have not been saved
,
then they will be discarded when the next EEG recording is opened or when
Persyst 15
is closed.
