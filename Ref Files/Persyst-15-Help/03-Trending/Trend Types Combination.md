# Trend Types: Combination

# **Trend** **Types: Combination**

**Combination:**
A Combination trend evaluates data from a user-specified list of existing two-dimensional trends, and plots either the mean, standard deviation, minimum or maximum value from that list as a function of time.

Method: The user specifies a list of trends, an operation to be performed on time-series data from that list (calculate mean, standard deviation, minimum or maximum value from that list), and an optional title for the trend. The output is plotted as a line graph.

- User-adjustable parameters:
- - For Combination trend calculations: a list of two-dimensional trends (line graphs) on which the Combination operation will be performed, and the combination operation: calculate mean, standard deviation, minimum or maximum value from that list.
  - For Combination trend graph: x-axis duration (timescale), y-axis range, color and optional fill color used for line graph, graph title.
- Parameter settings utilized in default trend examples (
  Trend Settings Version P15.mmx
  ) shipped with software: an example Combination trend is not included in the example file.
