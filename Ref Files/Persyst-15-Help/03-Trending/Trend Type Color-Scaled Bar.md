# Trend Type: Color-Scaled Bar

# Trend Type: Color-Scaled Bar

A color-scaled bar trend is used to show one or more 2-D trends so that the y-value is expressed as a color scale for plotting the trend.

Method: The user selects an existing 2-D trend for the z-axis, and an optional title for the trend. The output is plotted as a color-scaled bar.

·       User-adjustable parameters:

o   The two-dimensional trends (line graphs) used for the z-axis.

o   For color-scaled trend graph: x-axis duration (timescale), y-axis range, color scale used for z-axis, graph title.
