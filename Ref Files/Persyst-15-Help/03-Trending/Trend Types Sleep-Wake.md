# Trend Types: Sleep-Wake

# **Trend Types: Sleep-Wake State**

**Sleep-Wake State:** The Sleep-Wake trend is displayed as a color-scaled bar. (Refer to Performance Testing for information on the performance characteristics of Persyst sleep state algorithm.)

- User-adjustable parameters:
  - For EEG signal to be analyzed: none
  - For Sleep State graph: x-axis duration (timescale), y-axis range, and color palette for sleep-wake state.
  - Parameter settings utilized in default trend examples (Trend Settings Version P15.) shipped with software: Color-Scaled Bar: Trends: SleepWake, Palette: SleepWake, Number of Levels: 6 (only), Min/Max: 0-5. Line Thickness: 5.
