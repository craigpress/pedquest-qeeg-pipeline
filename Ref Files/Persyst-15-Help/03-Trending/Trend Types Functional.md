# Trend Types: Functional

# **Trend** **Types: Functional**

**Constant****:**
A
Constant trend plots a user-specified constant value as a function of time.

Method: The user specifies an epoch duration, a Constant value (number), and a name for the constant. The output is plotted as a lin
e graph.

- User-adjustable parameters:
- - For Constant trend calculation: epoch duration, Constant value (number), and a Name for the constant.
  - For Constant trend graph: x-axis duration (timescale), y-axis range, color and optional fill color used for line
    graph, graph title.
- Parameter settings utilized in default trend examples (
  Trend Settings Version P15.mmx
  ) shipped with software: an example Constant trend is not included in the example file.
