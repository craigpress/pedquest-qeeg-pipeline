# Trend Preferences: Notification Preferences

# **Trend Preferences: Notification Preferences**

Email
notifications can be configured to send an email with an image attached
for the current trend page and EEG waveforms when a Notification threshold
is exceeded. SMTP is supported for outgoing Email notifications.

Select
**Preferences|Trend Preferences**.
Select the **Notification
Preferences** tab.
