# Trend Type: Superposition

# Trend Type: Superposition

A Superposition trend is used to combine two 2-D trends so that the value of the second trend is expressed as a color scale for plotting the first trend.

Method: The user selects an existing 2-D trend for the y-axis and an existing 2-D trend for the z-axis, and an optional title for the trend. The output is plotted as a line graph.

·       User-adjustable parameters:

o   The two-dimensional trends (line graphs) used for the y-axis and the z-axis.

o   For Superposition trend graph: x-axis duration (timescale), y-axis range, color scale used for z-axis, graph title.

·       Parameter settings utilized in default trend examples (Trend Settings Version P15.mmx) shipped with software: an example Combination trend is not included in the example file.
