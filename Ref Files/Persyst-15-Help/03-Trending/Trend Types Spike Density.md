# Trend Types: Spike Density

# **Trend** **Types: Spike Density**

A SpikeDensity trend generates a graphical depiction of information contained in Spike text comments that were generated during Persyst Spike
Detector
’
s algorithmic analysis of an
EEG recording. An output value concerning spike detection frequency is plotted as a function of time.

Method: This trend utilizes “Spike” comments (detection and time) generated by the SpikeDetector algorithm in conjunction with an EventDensity trend th
at has certain parameters set to create a depiction of spike detection frequency as a function of time. The EventDensity trend parameters that are set (non-user-adjustable) are: Event Text (=”Spike”) and Origin (=”Detector”). The user can adjust the Epoch
Duration (seconds) and the Sum Type (see EventDensity Trend description: Count\_epoch, Count\_sec, Count\_min , Count\_hour Perception\_epoch, Perception\_sec, Perception\_min, Perception\_hour, Count\_overlap, Perception\_overlap).
Because Persyst only displays in
the Comments section detections with detection Perception value equal to 0.4 or higher, only “medium” or higher perception spikes are shown in this graphical representation of the spike comment data. The minimum Perception value is dynamically changed usi
n
g the Spike Detection Sensitivity selection of Low, Medium (default) or High. (Spike detections with Perception values of 0.1-1.0 are also available for detailed review in the Spike Review program.)

Note: A Spike Event consists of one or more Spike detec
tions occurring in different channels at (essentially) the same time. For example, a Spike Event might consist of four Spikes in channels F8, T4, C4 and T6. Each Spike is described by the height and duration of its front-half-wave, etc. The noted time ("z
e
ro time") of a Spike is given by the peak connecting its front-half-wave (FHW) and second-half-wave (SHW). The detection algorithm also calculates a perception value for each detected Spike, where an exemplar spike has a perception of 1.0, and a barely pe
r
ceivable spike (by the algorithm) has a perception near zero. The Spike with the largest perception value is called the Focal Spike of the Spike Event. For example, if the perception of a detection at T4 is 0.8 and the simultaneous perceptions of F8, C4 a
n
d T6 are all 0.4, then the Focal Spike is assigned to location T4. Spike detection is performed by the SpikeDensityV101 Calculation Engine, which can be viewed by selecting Preferences|Trend Preferences|Calculation Engines.
