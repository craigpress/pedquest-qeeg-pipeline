# Trend Preferences: Baseline

# **Trend Preferences: Baseline**

**Automatically find baseline segment:** Set an Automatic Baseline at the start of the recording to populate the VsBaseline trends based on the settings shown in the dialog (default selected).

**Baseline Search Parameters:** Sets the baseline time and duration after the start of the recording. The baseline is set if the Thresholds for Electrode Signal Quality, Seizure Detection, and Chewing Artifact are not exceeded during the Segment Duration.  

Start search at (sec): Automatic baseline search starts after the start of the recording in seconds.  
  
Segment duration (sec): Automatic baseline duration in seconds.

Search step (sec): Thresholds evaluated at the specified epoch step.  

**Thresholds:** The Automatic Baseline is set if the Thresholds for Electrode Signal Quality, Seizure Detection, and Chewing Artifact are not exceeded during the Segment Duration.
