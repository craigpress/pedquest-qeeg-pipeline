# **Trend** **Types: CNS Monitor**

The CNS Monitor Engine is used to redisplay trend data from non-EEG channels that have been recorded and trended by the Moberg Component Neuromonitoring System (CNS Monitor) manufactured by CNS Technology, Inc. The di
splay of trends for non-EEG (e.g., physiological monitoring) data is intended to be
used in conjunction with other
EEG trends, and with the original EEG waveforms, for analysis of the EEG.
