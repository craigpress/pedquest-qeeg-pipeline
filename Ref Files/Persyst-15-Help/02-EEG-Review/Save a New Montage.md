# Save a New Montage

### **Save a New Montage**

Now that you have made one or more changes to the current montage, you can save the changes in a new montage by right-clicking on one of the EEG channel labels on the Montage Bar, and then clicking **Save Montage** from the Context menu. You will be prompted for the new name of the montage.

The Persyst montages have preference over the recording system montages. (If a montage name exists in both the Persyst and Recording system montage lists, then the Persyst montage is used.) Thus, changes to the recording montages, e.g., different colors for the left and right channels, can be saved by saving the montage.
