# QuickKeys

### **QuickKeys**

Use the keyboard to perform some functions more quickly. These can be customized
by selecting Preferences|General Preferences|Keyboard.

### **Scrolling**

Home/End-
jump to the start/end of the record.

PageUp/PageDown-
scroll by one page.

Up/Down- scroll
a portion of a page.

SPACEBAR-
stop or restart automatic scrolling/paging/audio playback.

ESC-
stop a lengthy EEG page rendering.

### **Comments**

DELETE-
deletes the currently selected comment.

See
Preferences|General Preferences|Pre-Defined
Comments  to view or customize function key assignments.
