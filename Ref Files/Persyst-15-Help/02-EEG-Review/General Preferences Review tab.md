# General Preferences: Review tab

# **General Preferences: Review tab**

**As Recorded:**
If selected, the EEG waveform display will automatically follow the change in montage selections that were made during acquisition. (If this option is not supported for the current EEG file format then montage changes can be selected manually from the Montage button on the EEG Button Bar.).

**Beep on Remontage****:**
If selected, a system beep sound will play when a recording system montage change is encountered during playback. (For supported file formats.).

**Stop on Comment****:**
If selected, automatic EEG playback will stop when a recording system comment is encountered during playback.

**Beep on Comment****:**
If selected, a system beep sound will play when a recording system comment is encountered during playback.

**InPlay Insert Lag (sec)****:**
Comments can be placed by pressing a Function Key without stopping automatic playback. The Insert Lag is adjusted so that comments are placed at the desired time.

**AutoScroll Speed****:**
Adjusts the paging speed of the automatic EEG playback

**Print Settings:**
Include Patient Name and File Name on printed records.

**Copy comments to Manufacturers Comment List:**
Automatically copy Persyst comments to Manufacturer’s Comment List when processing/annotating EEG from Persyst stand-alone (non-integrated use).
