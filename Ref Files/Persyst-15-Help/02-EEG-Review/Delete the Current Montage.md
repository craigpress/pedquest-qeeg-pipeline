# Delete the Current Montage

### **Delete the Current Montage**

Right-click on one of the EEG channel labels on the Montage Bar, and then click **Delete Montage** from the Context menu to delete the current montage definition. After confirming the delete, all views with the deleted montage will be reset to the Recorded montage.
