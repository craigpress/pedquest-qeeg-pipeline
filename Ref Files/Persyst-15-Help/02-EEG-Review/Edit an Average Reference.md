# Edit an Average Reference

### **Edit an Average Reference**

Click **Edit Avg Ref** from the Edit Channel(s) dialog to edit an average reference.

![image\26AvgRef1.gif](../assets/26AvgRef1.gif)

![image\27AvgRef2.gif](../assets/27AvgRef2.gif)

After you add a new average reference, the list of G2 electrodes in the Edit Channel(s) dialog is updated.

**Note**: The average references A1A2, Av12 and Av17 are predefined by Persyst. Any changes you make to these references will not be saved.
