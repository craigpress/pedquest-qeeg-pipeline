# General Preferences: Display tab

# General Preferences: Display tab

**Font size (pts):**
Change the font size used to display channel labels in the Montage Bar.

**Show Trend Comments and Baselines:**
Select to display comments/annotations and the selected Baseline in the Comment Channel at the bottom of the trend display.

Show Times: Select to show times in the comment channel.

**Show Legend:**
Display a vertical scale at the right-end of each trend.

**Side Panels Font size (pts)
:**
Change the font size used in the Notification, Comments, and Electrode Signal Quality displays.
