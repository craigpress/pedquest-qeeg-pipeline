# Time Format

### **Time Format**

Times are displayed by default in the D:HH:MM:SS.HH. For example, the time 0:02:32:57.45 is zero days, 2 hours, 32 minutes, and 57.45 seconds.

Select Preferences|General Preferences|EEG Page Tab from the System Button Bar to change the time display format.

**Second Resolution:** Fraction of a second decimal resolution, e.g., “3” will display fractions of a second out to 3 decimal places.

**Date Format**

**None:** No date will be shown

**d1, d2,…** will show day 1, day 2, etc.

**YYYY.MM.DD** will show the complete date in year/month/day format.
