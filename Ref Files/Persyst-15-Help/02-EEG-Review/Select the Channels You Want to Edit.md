# Select the Channels You Want to Edit

### **Select the Channels You Want to Edit**

You can edit or delete one or more channels at a time, but you must first select the channels.

The Montage Bar supports drag rectangles for selecting channels. Channels can also be repositioned via drag and drop. Channels can be temporarily hidden as well.

![image\24ChannelSelectf.gif](../assets/24ChannelSelectf.gif)

Preset groups of channels are selected from the Montage Bar Context menu. Click **Select All** for all channels, or choose an item from the **Select Subset** menu.

![image\25ChannelSubset.gif](../assets/25ChannelSubset.gif)

Select a channel with the mouse by clicking on the channel name. Use the SHIFT key when you click to select a range of channels and the CTRL key to add specific channels to the selection.

Once you have selected the channels, again display the Context menu to edit or delete the channels.
