# Channel Select Dialog Description

# **Channel Select Dialog Box Description**

**(List)**

The Channel Select List allows single or multiple selections of channels to be used when writing the Archive File. You can include all of the channels in the original file to be written, or a subset of channels to remove unwanted channels. To select a channel, click that channel and it will become highlighted. To deselect a channel, click a highlighted channel and it will no longer be highlighted.

**Select All**

Click on the [Select All] button to automatically select all of the channels in the list to archive.

**Clear All**

Click on the [Clear All] button to automatically deselect all of the channels in the list. Note: you must have at least one channel selected or you will receive an error message if you click the OK button.

**OK**

Click [OK] when you happy with any changes you have made. This will close Channel Select Dialog.

**CANCEL**

Click [CANCEL] when you want to close the Channel Select Dialog without making any changes.
