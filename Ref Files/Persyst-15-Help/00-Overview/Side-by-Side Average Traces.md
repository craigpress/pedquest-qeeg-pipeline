# Side-by-Side Average Traces

# **Side-by-Side Average Traces**

Select **Side-by-Side Traces** from the **View** menu to compare the average traces of each group.

![image\200VplotSideBySideS.gif](../assets/200VplotSideBySideS.gif)

Select **Properties** from the **Format** menu to control which traces are displayed and their order.

![image\200VplotOrder.gif](../assets/200VplotOrder.gif)
