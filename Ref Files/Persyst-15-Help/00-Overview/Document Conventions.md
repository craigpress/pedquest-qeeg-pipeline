# Document Conventions

### **Document Conventions**

Screen elements are capitalized, e.g., Montage Bar. When the directions require you to select a screen element it will be highlighted with bold type. For example: select **Open** from the **File** menu.

Screen elements may be *italicized* when they are first introduced.

A shorthand convention is used to designate screen elements that require a number of steps. For example: **Start|Programs|****Persyst****|****Persyst** is used to indicate that the **Start** button should be pressed, the **Programs** menu selected, the **Persyst** program folder selected, and the **Persyst** program opened from the menu.
