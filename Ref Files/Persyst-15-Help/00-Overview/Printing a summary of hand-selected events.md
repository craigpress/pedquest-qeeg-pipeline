# **Printing a summary of hand-selected events**

Select **Tools** from the menu bar to print any tab's view. Select the PrintScreen button on your keyboard to copy the Final Report to the Windows Clipboard for pasting into a document. A paper or PDF print out of the FinalReport can be used to share abstracted information with other reviewers.
