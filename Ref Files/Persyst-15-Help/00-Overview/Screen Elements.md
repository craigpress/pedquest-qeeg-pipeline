# Screen Elements

# **Screen Elements**

The *Event List*, on the far right, includes all of the @VPlot comments from Persyst. Sort the list by clicking on the column heading of interest.

Just to the left of the Event List is the *EEG Bar*. This displays the channel tracings for the event(s) currently selected in the Event List. The average tracings of a group of events is found by selecting multiple events using the standard Windows SHIFT and CTRL key conventions with the mouse.

Just to the left of the EEG Bar is the *Montage Bar*, similar to the Persyst Montage Bar, which allows you to change the reference or delete channels. (See the section on EEG Review for details on using the Montage Bar.)

The EEG Bar, Montage Bar and Event List can be toggled on or off via the View menu or the toolbar.
