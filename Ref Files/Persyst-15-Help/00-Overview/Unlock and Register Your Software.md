# Unlock and Register Your Software

### **Unlock and Register Your Software**

Request Activation Key: Online Activation

This will register and unlock your software though the Persyst Activation Server.

1)    Launch the Persyst RegCenter by selecting Start|Programs|Persyst|RegCenter  
2)    Select Request Activation Key  
3)    Fill out the required information and then select Send online activation request.

If the Persyst Activation Server cannot be reached, or if activation fails for some other reason, please contact Persyst support.

Request Activation Key: Manual Activation

This will save the registration form to the desired folder location so you can attach the registration file (\*.xml) to an e-mail and send it to Persyst at support@persyst.com.

1)    Launch the Persyst RegCenter by selecting Start|Programs|Persyst|RegCenter  
2)    Select Request Activation Key  
3)    Fill out the required information and then select Save for manual request.

To save your registration file to the Windows Desktop: Select “Desktop” from the Save In list box and click Save.

Send your registration XML file to Persyst: Compose an Email to support@persyst.com. Attach the registration XML file to the email and we will process your unlock request.

Unlocking your Software

Your software key is in the form of a Persyst License Encrypted Key (\*.plek) file. This file will be sent to you as an e-mail attachment. When you receive the Registration Key Files, they will be named for easy identification with the Computer ID.

To unlock your software: 

1) Launch the RegCenter (Start|Programs|Persyst|RegCenter).

2) Click Apply Activation Key, select the .plek file and click Open.   
3) The purchase date should appear across from the purchased Persyst 15 software components.

Contact Persyst Support at 928-708-0705 if we can be of any assistance with registering and unlocking your Persyst 15 software.
