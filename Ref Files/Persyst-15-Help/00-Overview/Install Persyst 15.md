# Install Persyst 15

# **Install** **Persyst 15**

The
Persyst 15 installation ***requires that you log on with administrator privileges***
.
If you do not have a login with administrator privileges
,
contact your system administrator.

***Install the*** ***Persyst 15******Software***

Launch the Persyst installation by double clicking on the file **SetupP15.exe**
from Windows Explorer.

1. 1. Open the Persyst 15 installation folder in Windows Explorer.
   2. Run **SetupP15.exe**
      From Windows Explorer.
   3. Select **Install** **Persyst 15**
      .
