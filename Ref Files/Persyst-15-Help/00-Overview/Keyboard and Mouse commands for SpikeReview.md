# Keyboard and Mouse commands for  SpikeReview

# **Keyboard and Mouse commands for SpikeReview**

Keyboard:

1. 1. PgUp/Dn to scroll a full page.
   2. Up/Down arrows to scroll a single spike (and control which spike is selected)
   3. Right/Left arrows to
      page through individual spike detections.

Mouse:

1. 1. Mouse wheel to scroll a full page.
   2. Left click to Select or Confirm a spike.
   3. Click on FinalReport – Jump to Spikes.
   4. Double-click on a waveform average/spike group – Expand/Unexpand selected spike group.

Note (1) To use SpikeReview, an EEG recording must first be processed (either during acquisition or offline) using an mmx file containing the SpikeDensity
trend
. This causes the Persyst SpikeDetector neural network algorithms to analyze the recording.
