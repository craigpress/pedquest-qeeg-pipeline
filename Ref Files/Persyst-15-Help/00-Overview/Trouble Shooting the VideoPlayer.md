# Trouble Shooting the VideoPlayer

# **Trouble Shooting the VideoPlayer**

#### “Wrong file type selected or file is corrupted [filename]!”

If you receive this error message, then most likely you are trying to open a file whose file type is not supported by the VideoPlayer.

#### “No video files found for file [filename]!”

If you receive this error message, then most likely there are no Video files recorded for the EEG file you have opened with Persyst. Verify that the file you have opened with Persyst is the correct record and contains recorded video files.

#### After opening an EEG file and then choosing the VideoPlayer from the View menu, the Video image displayed is of poor color quality

If the video image displayed by the VideoPlayer is of poor quality, you may need to increase the number of colors currently being used in your display settings. Choose Start->Settings->Control Panel, then open up your Display Properties and verify under settings that you have at least 16-bit color depth selected.
