# Video Trim Options Dialog Box Description

# **Video Trim Options Dialog Box Description**

![image\31VideoTrim.gif](../assets/31VideoTrim.gif)

**Match source media parameters**

Selecting this option will disable the other Audio stream options and will set the output file quality equal to the source file quality.

**Exclude from archive**

Selecting this option will disable the other Audio stream options and will exclude the Audio stream from the output video file. This will result in a small video file size at the expense of having no audio. Use only if there is no audio track of interest in the video recording. The resulting video file will use the default quality setting that is blend of video quality and video compression.   
  
**Quality**

This option sets the audio output quality of the video file. The default setting is CD-ROM, which has the largest file size but produces the best audio quality. Each of the other settings produces descending smaller files along with a corresponding decrease in audio quality.  
  
**Mono (1 channel)**

Selecting this option will produce a single channel audio stream. This is the default mode.  
  
**Video Codec**

Selects the video codec that will be used to write the archived video.  
  
**Audio Codec**

Selects the audio codec that will be used to write the archived audio..
