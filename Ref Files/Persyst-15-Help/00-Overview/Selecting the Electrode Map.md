# Selecting the Electrode Map

# **Selecting the Electrode Map**

Select **Properties** from the **Format** menu and change **Propagation|Rows** and **Propagation|Columns** back to **1**. On the **Topograph** tab, select **Electrodes**. Change the electrode map from 10-20 to **10-20 Ex Tape** via the lower toolbar.

![image\200VplotMapSelectS.gif](../assets/200VplotMapSelectS.gif)

The predefined map **10-20 Ex Circle** includes the extended 10-20 electrodes mapped onto the circle (Sharbrough, Current Practice of Clinical EEG). **10-20 Ex Tape** includes the extended 10-20 electrodes positioned by "tape measure distance" (Lagerlund, et. al. EEG. Electroenceph. Clin. Neurophsiol., 86(1993) 7-14).

Only the active electrodes are used in the calculation of the voltage plot.
