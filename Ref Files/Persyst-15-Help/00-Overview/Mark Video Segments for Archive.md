# Mark Video Segments for Archive

# **Mark Video Segments for Archive**

Event Text that is designated to Archive Video will direct the EEG Archive tool to clip EEG and video for the portions of the recording that are marked with the appropriate Event Text. (See the help topic Add/Edit Events Dialog Box Description.

## During the creation of each trimmed video segment file, a progress dialog will be displayed with a Cancel button to allow stopping of the video archive process.
