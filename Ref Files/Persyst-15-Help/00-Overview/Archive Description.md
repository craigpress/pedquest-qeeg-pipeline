# Archive Description

### **Archive Description**

**Export an** **EEG recording** **to a new file** **containing only** **the data you are interested in.**

The Archive Tool will scan a recording for specific events it will create a new file with EEG and video (for supported EEG and video formats). The time preceding and following the events you specify is user-selectable. You can select single or multiple event types for archival. Noisy or unused channels can be excluded from the archive to reduce storage requirements.
