# **Create @VPlot Events**

The @VPlot events are created as Persyst comments. In addition to creating VPlot comments automatically from Spike Review, you can hand-mark @VPlot events (e.g., spikes or any series of events for back-averaging). Activate **Persyst** by selecting it from the **Taskbar** (bottom of Windows desktop). Select the **Comment** button on the EEG toolbar and then **Pre-defined comments…** from the Add Comment dialog.
