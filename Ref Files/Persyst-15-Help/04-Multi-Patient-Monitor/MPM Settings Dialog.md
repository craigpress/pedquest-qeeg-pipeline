# MPM Settings Dialog

# **MPM Settings Dialog**

Selecting the Settings button in the upper-right corner of the MPM display will launch the main settings dialog.

![image\102MPM1.gif](../assets/102MPM1.gif)

The Grid tab dialog is used to set the number of columns and rows. The mode for each display cell (Manual, Automatic, or [Station] can be selected from this dialog as well.

Exit full screen after period of activity will automatically return the MPM display from a single recording in full-screen to displaying all the cells.

![image\103MPM1.gif](../assets/103MPM1.gif)

The Window Settings dialog is used to set the display attributes for each cell, the Paused and Stopped timeout settings, and the Panels Layout Settings to pin or un-pin the Numeric Display, Comment List, and Electrode Status Display within MPM.

The Trend panel to show list allows you to specify a Trend Panel for display within MPM, or to use the same Trend Panel that is selected on the EEG acquisition system.

![image\103MPM2.gif](../assets/103MPM2.gif)

![image\103MPM5.gif](../assets/103MPM5.gif)

The Locations tab is used to add, remove, or modify EEG recording locations to be monitored with MPM.

![image\103MPM3.gif](../assets/103MPM3.gif)
