# Multi Patient Monitor Description

# **Multi Patient Monitor Description**

Multi-Patient monitor (MPM) is intended to be used for real-time monitoring of EEG during acquisition. Acquisition of EEG is done externally to the MPM.

Multi Patient Monitor provides the ability to monitor multiple records on an individual monitor. The recordings are displayed in a grid with dimensions specified by the user. The software is able to support multiple monitors on the same computer and the user can specify different dimensions on different monitors.
